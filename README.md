# Ardoise 🃏

> **Web App PWA** — Compteur de scores ultra-minimaliste pour jeux de cartes et de société.

**URL** : [ardoise.art-crea.fr](https://ardoise.art-crea.fr)

## Stack

- ⚡ React (Vite)
- 🎨 Tailwind CSS v4
- ✨ Lucide React
- 🎉 Canvas Confetti
- 💾 LocalStorage (100% offline)

## Jeux intégrés

| Jeu | Description |
|-----|-------------|
| 🃏 Caracole | Pénalités par cartes restantes |
| 🏆 Président | Rangs et rôles par manche |
| ☁️ Skyjo | Fin à 100 points |
| ♠️ Belote/Coinche | 2 équipes, 162 points |
| 🔮 Tarot | 3–5 joueurs, contrats |
| 🐂 6 qui prend ! | Têtes de bœuf, élim. à 66 |
| 🎲 Compteur libre | Mode libre configurable |

## Développement

```bash
npm install
npm run dev
```

## Déploiement

Cloudflare Pages avec déploiement automatique sur `git push` vers `main`.

## Fonctionnalités

- 📱 PWA installable (mobile-first)
- 🌙 Mode sombre / clair avec persistance
- ↩️ Undo de la dernière manche
- 🏆 Podium avec confettis dorés
- ⚡ Revanche immédiate
- 📋 Historique des parties
- 👥 Bibliothèque de joueurs mémorisés
